**Lab Objective**

Participants will design and configure a complete CI/CD pipeline for a ReactJS application using Jenkins Freestyle Job, starting from GitHub source code to a production-ready build. 
  
**Problem Definition**

Your team has developed a ReactJS web application using Node.js tooling. 
Management wants:

•	Manually build on every GitHub change

•	Execution of unit tests 

•	Generation of a production-ready build 

•	CI/CD configured using Jenkins (Freestyle Project)
